# Manuals

- `XSR700-2022-MTM660N-owners-manual-AU.pdf` (BEE-28199-20): official Yamaha owner's manual for the
  Australian **MTM660N** (the learner-approved/LAMS variant of the XSR700, hosted by a Yamaha dealer). The meter, controls,
  fuses and battery should match the US bike closely, but this is not the US MY2025 edition.
  Use it for chapter 4, "Instrument and control functions": what the stock meter displays and how its modes work.
